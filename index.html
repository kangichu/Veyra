How it works

From a property search to relevant listings.

EmbeddingsRepresent listing text for similarity search
Vector SearchRetrieve listings by similarity
Multi-signal RetrievalCombine semantic and structured retrieval
Relevance RankingOrder results by relevance
RuntimeLocal processing in your environment
API ResponseResults return to the tools your team already uses

Veyra extracts supported property criteria using defined rules. Semantic and structured retrieval work together to surface relevant candidates, which are ranked before the API returns results. Processing stays in your Veyra environment. Search quality and query coverage are being refined.
