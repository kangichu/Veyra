Know what kind of result came back.

Full match: satisfies the explicit requirements. Weak match: meets required constraints but may miss softer preferences.

Relaxed match: an alternative that falls outside an explicit requirement, labeled to make the compromise clear.

Conflicting query: the request contains contradictory requirements. No match: no acceptable result was found within the bounded search.

How search works

Veyra interprets supported property criteria from the request, combines semantic and structured retrieval, applies explicit constraints, orders valid candidates and validates the outcome before returning results through the local API. Processing stays inside the Veyra environment. Search quality and query coverage continue to be refined.

01 / Understand

Query understanding

Extract supported property criteria from natural-language requests using deterministic rules and canonical property semantics.

02 / Retrieve

Semantic + structured retrieval

Surface candidates using semantic similarity together with structured property signals.

03 / Check

Constraint enforcement

Check explicit requirements such as location, bedrooms, area and exclusions. Any relaxed alternative is identified separately.

04 / Order

Result ordering

Order valid candidates by relevance, keeping full matches ahead of weaker or relaxed alternatives.

05 / Validate

Outcome validation

Distinguish full, weak and relaxed matches, detect contradictory requirements and identify no-match outcomes.

06 / Return

API response

Return results with their actual outcome state so your application can show what matched and what did not.

Details for your technical team

Your backend calls the local /v1 API with project API keys. Projects hold the datasets, index bindings and local configuration used by search and recommendations. Local administration manages projects and application access within your deployment.

Veyra is deployed with Docker on customer-controlled infrastructure. Listing imports use REST, JSON or CSV approaches. Data mapping, updates and application changes require integration work; a generic direct database connector is not currently available.

Hosting requirements, security configuration, licensing and operational responsibilities are reviewed for your deployment.
