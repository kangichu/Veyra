Deployment & operation

Local intelligence.
Defined responsibilities.

Property search and intelligence run in your Veyra environment. Tandish provides the commercial licensing and release control plane.

Your environment

  • Docker/containerized customer deployment.
  • One active engine-platform replica per V1 installation.
  • Customer-configured TLS, hosting, network and storage.
  • Logs in the customer or container environment.
  • Local models operate locally after acquisition.

Tandish's role

  • Commercial licensing and entitlements.
  • Signed software releases and update authority.
  • A separate minimal deployment agent for controlled container updates.
  • Deployment and operational requirements discussed for your environment.
Self-hosted does not mean permanently disconnected.

Periodic communication with Tandish is part of licensing and rights validation. An offline grace mechanism exists; Veyra is not a fully air-gapped product. Security and compliance depend on the deployment, configuration and operational arrangements.

API-first integration

Your application backend connects to the local Veyra /v1 API using project API keys. It can request search results and recommendations, plus price intelligence where configured and licensed. Veyra manages the project resources and local configuration.
